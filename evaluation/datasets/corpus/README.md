# RAG 评测冻结语料

这些 JSONL 是 `rag-v1` 题集配套的完整政策片段快照，每行保存索引中的原始 payload。它们包含正文、出处、内容哈希、抓取时间和适用范围，未按题目答案筛选或改写。

| 场景 | 完整片段数 |
|---|---:|
| 美团骑手 | 95 |
| 美团商家 | 252 |
| 滴滴司机 | 623 |
| 度小满金融咨询 | 315 |
| 合计 | 1285 |

保存完整语料能让新学员在相同候选集合上评测，也保留容易混淆的非答案片段。如果只导出题目命中的标准证据，检索任务会变得过于简单。

默认运行时使用的 [backend/agent_harness/rag/knowledge/v1/](../../../backend/agent_harness/rag/knowledge/v1/) 教学包与这四份冻结语料的分块内容一致，额外保存 42 份整理正文、文档元数据和文件哈希，随 Git 一起发布。教学包不包含原始网页或 PDF；项目文件路径不包含作者的本机用户目录。

执行 RAG 评测时，运行器先尝试复用 PostgreSQL 中语料版本完全一致的生产索引。版本不同或没有生产索引时，自动在独立评测 namespace 中复用或建立索引，生产知识库保持原样。构建使用同一个 `PolicyIndex`、BGE、pgvector、BM25 和 RRF；首次运行可能下载开源向量模型，后续复用 `.run/knowledge/models/` 中的缓存。评测不重新抓取政策网页、不调用付费云模型。

构建前按 `PolicyIndex.build` 的原始算法计算完整快照的 SHA-256，必须等于对应 RAG 题集的 `corpus_version`；构建后再次验证索引版本和每条 gold 的出处、哈希与原文。语料、分块或适用日期变化造成版本不一致时会明确停止，不静默改写 gold 或输出不可比较的分数。默认预览不会建库、加载模型或下载文件。

这些材料说明的是题集冻结时的公开资料。冻结只固定语料输入，检索仍按实际日期过滤政策有效期，跨日期运行时可用候选和分数可能变化；云端对话模型的采样结果也不保证逐字复现。RAG 分数衡量冻结语料中的检索效果，不代表政策始终现行有效。更新冻结语料时应同步审阅题目、全部相关片段及标注版本，不能只替换快照文件。
