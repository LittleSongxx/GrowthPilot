# 语音体验与验证

当前链路为 **自动断句 → 完整录音 ASR → AgentScope Agent 最终回答 → 流式 TTS → 边收边播**。页面选择场景并开始通话，允许麦克风后直接说话，后续发言无需再点击按钮。观察转写、查询、回答和实际播放。

建议四场景分别覆盖：

- 政策问题与当地业务查询组合，例如年龄要求、站点、收入和用车成本。
- 客户口头更正地点或条件，Agent 使用最新信息继续解答。
- 客户表示完成下载或注册，Agent 依据反馈指导下一步。
- 事项办妥后客户回应可以收尾，或明确拒绝、告别、表示没空，Agent 简短道别，实际播完结束语后挂断；仅短信发送成功不代表可以收尾，客户仍有新问题时继续回答。
- 结束语播放期间插话，会话继续；旧一轮结束请求不会在稍后挂断通话。
- 一次开始后连续聊多轮；句中短暂停顿不应过早提交，说完后能自动提交。
- 在开场、查询和回复播放中插话，旧声音立即停止，旧一轮结果不会随后继续播放。
- 扬声器外放时，Agent 的声音不会被当成客户插话；分别检查安静环境和背景噪声。
- 静音后发言不提交，取消静音后可继续说话。
- 重播已完成的回复可直接播放；TTS 失败后只重试语音，不重复工具调用。结束语合成失败时保持通话，重播同一句结束语并实际播完后才挂断。
- 请求处理中结束通话，或直接关闭页面，麦克风和音频播放均停止。

回答引用实际取得的工具结果与政策正文。联系人和金额按返回值使用，必要条件和费用假设说清楚。无借款需求时介绍 App 功能，不主动转成借款推荐。

插话停止旧一轮的 Agent 回答和 TTS，会话仍可继续；结束通话取消当前处理并释放资源。自动挂断由系统通话工具请求，普通回复或仅口头道别不会触发。页面关闭释放媒体并尽力通知后端；服务端会话期限处理未送达的关闭。ASR 与 Agent 仍需完成当前阶段，流式播放缩短的是 TTS 等待，不能据此认定整条链路已经全流式。

链路探针使用临时应用数据库，不代替真人试听。人工验证记录场景、输入、转写、回答、设备、播放情况和发现的问题；延迟分别记录说完到提交、提交到转写、转写到回答、回答到首段音频和实际起播。未测设备和延迟保持未知。文本对话、语音探针和真人体验分别记录。
