# 本地业务目录

四个场景的 12 个业务工具通过 `BusinessCatalog` 读取本地版本化数据。查询依次使用精细记录、城市参数配置、通用方案，返回适用条件、费用、服务信息与有效期。所有记录统一标记 `source_type: local_catalog`，不是品牌官方实时来源。

当前目录包含 42 条精细记录、北京望京与中关村 2 个商圈、60 个城市配置、4 档参数、11 类方案模板和 67 个条件分支。每次最多返回 4 个适用方案，不把全量城市与模板内容传给模型。

## 文件与入口

- 各场景的 `catalog.json`（如[骑手目录](../../scenarios/meituan_rider/catalog.json)）：业务记录、城市参数、方案模板、来源与有效期。
- [catalog.py](catalog.py)：场景隔离、参数验证、记录查询与金融费用计算。
- [expansion.py](expansion.py)：条件匹配、方案生成、确定性 ID 与联系人。
- [locations.py](locations.py)：地名解析与地区范围。
- [pricing.py](pricing.py)：城市价格参数与金额计算。
- [tools/](../tools/)：模型可调用的类型化接口。

场景 `business_data.ref` 指向 `catalog.json`。配置在创建会话时冻结进 `Scenario.resources` 并参与快照哈希；查询不读取可变价格文件、不调用模型生成数值。同一快照和业务输入的结果跨进程稳定，有效期则按查询时间检查。

## 地点与条件匹配

`长沙`、`我在长沙`、`长沙市岳麓区`、`湖南长沙`、`广东深圳`等表达可直接查询城市方案（省名可作城市前缀）；`望京`、`中关村`等已收录商圈可单独查询。未收录县城或商圈使用独立通用配置，不借用北京精细记录。同城多地标按城市范围返回；不同城市冲突、没有位置或参数无效时要求澄清。同名街道、镇乡村不会被直接认作城市证据。

60 个城市为：北京、上海、广州、深圳、天津、重庆、成都、杭州、南京、武汉、西安、苏州、郑州、长沙、青岛、宁波、东莞、佛山、济南、合肥、福州、厦门、昆明、沈阳、大连、哈尔滨、长春、石家庄、太原、南昌、南宁、贵阳、兰州、乌鲁木齐、呼和浩特、海口、银川、西宁、拉萨、无锡、常州、温州、泉州、南通、徐州、嘉兴、绍兴、金华、台州、烟台、潍坊、临沂、洛阳、唐山、保定、珠海、惠州、中山、绵阳、赣州。

参数档位影响单价、司机计费、租金、押金及商家服务费；条件分支区分众包／专送、含／不含电池、快车／专车、车型、门店类目及新老客户。档位来自配置，不代表城市实际收入、价格或经济等级。`requested_filters` 保留客户条件，`assumed_filters` 和条目的 `eligibility_filters` 表示所用方案条件；未知条件不会被写成已核验资格。

## 联系方式与业务内容

骑手站点、司机服务中心及租赁方案提供 `address`、`phone`。14 个精细实体的联系方式保存在目录中；城市和通用实体按业务类型、规范化地区与方案条件生成稳定联系人键，再生成地址和**不可拨打的占位号码**（形如 `000-XXXX-XXXX`，唯一且跨进程稳定）。14 个精细实体与生成实体使用同一套占位格式，**全部是教学虚构数据，不可拨打或到访**。联系人键独立于模板名称与对外 ID，后续重命名不会改变联系方式；接入真实数据源时应替换为只读适配器，不能把占位号码当成业务线索。

“我在”“附近”“这边”等口语保留在 `requested_location`，不进入实体身份与地址。站点招募、租赁库存和到访安排需向服务方确认。未计算 GPS 距离，`distance_meters` 为 `null`，不能据此判断最近网点。站点 ID 与地区、配送类型绑定；计酬查询拒绝跨区域、错类型或伪造 ID。

商家活动提供运营、配送或推广服务券，保留领取方式、使用范围、有效期及不可提现条件，不承诺订单增长或已取得活动资格。金融活动提供账户费用、还款信息和安全通知服务，不以借款换取奖励、不承诺授信。

## 结果与审计

结果结构为 `status / data / evidence / retryable`。正常业务视图保留名称、联系方式、金额、条件、包含项、排除项、有效期和计算假设；内部来源、生成参数与诊断由 [model_projection](../tools/boundary.py) 和前端过滤。独立 RAG 的官方政策来源及证据不受这一过滤影响。

| 字段 | 用途 |
| --- | --- |
| `source_type` | 本目录为 `local_catalog`，用于内部来源识别 |
| `match_type` | `curated_locality / city_profile / generic_fallback` |
| `coverage_level` | `locality / city / generic / not_applicable` |
| `requested_location / matched_location` | 原始位置与采用范围 |
| `requested_filters / assumed_filters` | 客户条件与方案条件 |
| `template_provenance / pricing_basis` | 来源、参数与计算依据；仅用于内部审计 |
| `unverified_conditions` | 尚未核验的服务范围、准入或账户资格 |

`success` 表示有有效方案；`needs_clarification` 表示输入缺失、歧义或无效；`no_data` 表示没有可用数据；`expired` 表示数据过期；`denied` 表示跨场景或工具边界拒绝。当前有效期为 2026-10-01 00:00 UTC 至 2027-11-01 00:00 UTC，不含终点；该时间窗在目录中重复内联，到期会整份同时失效，更新时应整体替换。精细记录、城市配置和模板分别校验有效期，已过期的命中不会通过通用方案重新生效。业务 JSON 的配置约定由测试覆盖。

## 金融信息与计算

金融配置含 7 个信息分支与 5 个费用分支。登录、注册、账单、安全信息等目的返回 `app_information`，不携带借款金额或利率、不支持融资费用计算。未知目的默认信息说明；明确费用、利息问题才使用费用方案。明确没有借款意愿时优先提供信息。

未知产品保留 `requested_product_id`，以 `effective_product_id` 表示实际采用的通用方案。费用计算使用 `catalog_generic_financing`，不能视为原产品或客户实际条款；信息类 ID 不会自动转换为融资产品。已知基础产品 ID 为 `catalog_flexible_loan`。

费用按显式条款用 `Decimal` 计算并四舍五入到分。通用方案为 12% 年利率、按月单利、到期一次还本付息：10,000 元、3 个月对应利息 300 元、到期应还 10,300 元。结果包含公式、假设及 `personal_quote: false`。负数、非有限值、布尔值、厘精度金额、超出金额范围或不支持的期限仍拒绝；提前还款、逾期等不在当前计算范围。

## 替换数据来源

接入其他业务来源时，在 `ToolContext.catalog` 绑定目录的位置引入只读适配器，保持结果结构、来源、适用条件、有效期和未知结果约定。外部接口失败不能静默切换为本地价格。变更需验证快照、地点别名、条件匹配、有效期和跨工具 ID。

本目录不修改客户记忆、注册状态或外部账户，不要求注册回执、操作账本或状态监听。
