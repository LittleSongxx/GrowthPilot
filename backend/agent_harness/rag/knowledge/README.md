每个 `documents/<来源标识>/` 保留三类文件：`clean.txt` 是清洗后的完整正文，`chunks.json` 是固定分块，`document.json` 保存官方 URL、采集时间、原始响应内容哈希和适用范围。正文与分块沿用已有采集结果，不按评测答案筛选或改写。加载后的全部分块与 `evaluation/datasets/corpus/` 中的 `rag-v1` 冻结候选集合一致。

`catalog.json` 登记所有文件的相对路径和 SHA-256，并记录逐场景的分块版本；`catalog.sha256` 校验清单本身。程序先验证完整性和四场景覆盖，再构建检索索引。文件缺失或内容变化时会停止，并提示恢复对应版本，不通过重新抓取网页掩盖差异。校验和用于发现复制损坏或非预期修改，不能代替对新版本内容的审核。

原始 HTML、PDF 和接口响应不随本教学包分发；`content_hash` 对应采集时的原始响应，不能从清洗正文反推或验证。当前分发文件自身的完整性由清单中的独立 SHA-256 校验。复现检索只需固定分块，不需要再次访问这些来源网页。

福州网约车驾驶员从业资格办理指南在采集时因官方站点 `robots.txt` 返回 HTTP 403，未取得快照，已在清单的 `unavailable_sources` 中明确列出，不参与检索。福州网约车办法等其他已取得资料仍正常保留。

固定语料版本不保证政策在任意日期仍然生效。所有原始生效、失效日期均被保留，检索仍按实际日期排除不适用资料；例如福州网约车办法的已声明有效期截至 2029 年 3 月 26 日。该日期之后，可检索片段会减少，但原始教学材料及其版本不变。

更新教学资料时应创建新的版本目录，审阅新增或变更的正文、来源、适用范围与缺失来源，重新生成文件校验和及逐场景版本，并同步检查对应评测题集。不要直接覆盖 `v1/` 的正文或仅修改校验和。模型文件属于可重新下载的本地缓存，不属于教学语料。
