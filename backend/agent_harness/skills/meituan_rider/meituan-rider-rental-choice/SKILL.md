# 无车起步与租赁方案比较

## 适用与边界

- 解决“没有车怎样起步”“这份租车方案是否适合我的使用计划”。
- 主要结果是比较方案适配性；整月收入能否覆盖成本交由成本规划技能处理。
- 不判断车辆实际车况、实时库存、合同法律效力或未披露的赔偿责任。

## 最少信息

- 查询需要一个明确城市；只在城市歧义时澄清，不必强索详细住址。
- 客户准备试跑多久、能接受多少首期现金占用，以及是否已有可用电池或补能安排。
- 配送类型和车辆要求在影响选择时再确认；不要把“没有车”直接解释成必须租车。

## 判断与推进

1. 先明确是短期试跑、长期使用，还是仅了解价格；已有车辆的客户不默认推荐租车。
2. 需要确认车型是否能用于配送时，先以适用政策解释车辆要求；有租赁目录记录不等于车辆已经通过当地或平台准入。
3. 对每份候选方案按同一组条件比较：月租、押金、最短租期、电池服务、维修包含项、明确排除项。
4. 先排除期限冲突。例如客户只试一个月，最短租期更长的方案即使月租较低，也不能称为更适合试跑。最低租期匹配只说明已知门槛不冲突，不证明实际合同仅签该期限、没有续租或提前通知要求；退出限制仍需核对。
5. 再比较完整费用口径。裸车方案不含电池且补能价格未知时，可指出待补费用，不能直接断言总成本最低。
6. 把押金与持续成本分开：押金影响首期现金占用，是否可退及扣退条件按已知条款解释，不能把目录中的押金金额等同于无条件退还。
7. 维修包含自然损耗但排除人为损坏时保留这一区别；未列出的换电、保险、逾期或配送费不自动视为免费。
8. 两份方案费用尚不能同口径比较时，仍交付期限、服务包含项和现金占用的已知差异；明确哪一项报价补齐后才能比较总成本。
9. 最后给出条件判断和签约前关键待确认项，不声称已锁车、已联系服务方或可以现场立刻提车。

## 完成与停止

- 完成：客户知道候选方案的适用条件、明显冲突和影响选择的未知费用，而非只得到最低月租。
- 不适合当前试跑期限、暂缓租赁均可完成；客户接受条件且想核对成本时，再转入成本规划；下一步最多提供客户已知条件下的成本门槛或预算，不主动承诺估计真实单量、跑单收入或多久回本。
- 询问具体违约金、退租扣款而无对应合同条款时，只指出缺少的约定，不虚构计算规则。

## 正反例

- 正例：客户想试跑一个月。返回方案里有短租和更长最低租期，先比较期限；若低月租方案缺电池报价，说明其总成本尚不能与含电池方案直接比较。
- 反例：“裸车月租更低，所以最划算；押金一定全退，车源也已经给您留好了。”这补造了完整成本、退款与库存状态。

## 能力依据

- `search_vehicle_rentals`：目录提供租金、押金、最短租期、电池、维修与排除项；没有完整退租条款和实际库存。
- `search_policy`：已配置来源 `meituan-rider-faq`、`meituan-rider-service-standard`，仅使用当次返回的适用车辆或配送要求。
- Agent 负责期限冲突、服务包含项和预算偏好对照，不替缺失合同条款生成结论。
- 来源已配置不是检索成功证明；本技能不要求额外读文件、合同系统或实时库存接口。
