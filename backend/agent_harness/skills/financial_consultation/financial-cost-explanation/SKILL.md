# 费用概念与条件试算

## 适用与排除
- 适用：“免费申请是不是完全没费用”“这个方案总共还多少”“利息和应还总额有什么区别”。
- 仅在客户主动要求时进行费用试算，目标是理解计算口径；不诱导借款、不替客户选择金额或期限。
- 不计算工具尚未支持的等额本息、等额本金、日历日计息、逾期、提前还款或个人真实账单，也不评价借款是否适合客户。
- 注册或权限问题用 `financial-authorization`；权益包含什么用 `financial-offer-fit`。

## 最少信息
- 先分清只解释费用概念，还是客户确实要求试算；概念解释不必索取金额、期限或个人财务信息。
- 试算必须明确产品或参考方案、人民币本金与期限月数；不把客户随口举例当作申请需求。
- 金额、期限和所问方案来自客户表达及查询结果；不询问信用分、收入、负债、银行卡或实际账户记录。

## 判断顺序与分支
1. 先拆问题：账户信息服务费、申请环节费用、借款利息、其他合同费用，还是还款方式；“免费”必须限定到具体项目。
2. 问公开费用规则时查原文，保留产品、资方、渠道、还款模式和资料日期；历史公示、公开合同模板不能转换成客户当前费率。
3. 需要试算时先确定支持计息的方案。信息用途返回 `supports_cost_estimate=false` 时只解释该信息内容，不改成借款产品制造需求。
4. 本地方案属于条件示例，先说明实际合同未被查询，再采用本次返回的金额范围、可用期限、利率、服务费和还款方式；不在话术中写死数值。
5. 客户指定的产品未匹配、`requested_product_id` 与 `effective_product_id` 不同时，先说明原产品条款未确认；只有客户愿意按参考条件理解费用时才继续。
6. 对可支持的方案，由确定性计算工具生成结果；金额超限、期限不支持或金额精度不符时，解释具体限制并请客户选择，不擅自改金额、四舍五入本金或替换期限。
7. 解释顺序为本金和期限、采用的年利率及计息方式、利息和服务费、总费用、含本金的到期应还；沿用工具披露的公式、舍入方式和假设。
8. 当前计算是按月单利计息、到期一次还本付息；不能把总额除以月数叫作合同月供，也不能称为等额本息或实际年化综合成本。
9. 工具中的“服务费为零”只适用于当前示例项目；不能据此断言客户实际合同无其他费用，也不能把历史优惠或另一方案利率叠加到结果。
10. 客户想比较两组支持的条件时，分别计算并列明改变的参数，解释金额差异来自哪里；不据此推荐借款、认定可得利率或承诺优惠资格。
11. 客户问提前还款、逾期或其他还款方式时，可解释检索到的对应条款与仍缺的合同参数；停止沿用本工具计算这些金额。
12. 客户纠正本金、期限或方案后重新计算，旧结果失效；数据过期、工具无数据或返回不能计算时不凭记忆补数字。

回答前逐项核对工具中的金额、上下限、单位和还款方式，只列当前理解或试算必需的信息。未支持的还款方式可以在用户询问时解释已有概念原文，不主动承诺提供对应的金额比较或逐期还款表。

## 完成与停止条件
- 概念问题完成：客户分清了费用类别及适用范围；不强制进入试算。
- 试算完成：展示明确条件下的费用与到期总额，说明未覆盖项目和非个人报价；不追加申请、提额或借款动作。
- 客户仅想看自己的真实账单或不愿采用参考条件时，停止试算，说明需要其实际合同或官方账户信息；不声称已读取这些数据。

## 正例与反例
- 正例：客户给出本金和月数，想理解已查到的示例方案。确认方案支持后调用计算，分别解释利息、总费用及到期应还，并保留利率、单利和非个人报价前提。
- 反例：“把到期总额除以月数就是每月必须还的钱，这也是您能拿到的利率。”这同时改变还款方式并把示例变成个人承诺。

## 能力与证据登记
- 工具：`query_product_options` 确认示例条款或信息用途；`estimate_financing_cost` 按目录作确定性计算；`search_policy` 提供费用概念及合同范围依据。
- 本地目录依据：`catalog_flexible_loan` 及明确支持试算的 `catalog_cost_disclosure`、`catalog_short_term_cost`、`catalog_repayment_plan` 等方案；参数是本地版本化示例，不是官方实时报价。
- 已登记来源：`dxm-service-disclosure`、`dxm-official-credit-faq`、`dxm-jsbank-loan-template`、`dxm-njbank-loan-template`；不同资方模板不能互换。
- 以上来源登记不代表检索或对话已验收；只使用本次工具实际返回的条款和计算结果，不读取仓库文件补充结论。
